# v0.3 Process Hacker 兼容性复查

复查日期：2026-08-31

## 修复原因

v0.2 会从每一个字节偏移开始把相邻两个字节解释成 UTF-16，并接受绝大多数非控制码位。随机二进制因此产生大量错位、重复和不可读结果：实测 1.75 GiB 内存得到 48,140,083 条记录，导出约 2.95 GiB。

## 兼容规则

v0.3 使用 Process Hacker 2.39 `memsrch.c` 的字符串状态机：

- 可打印字节为 TAB、LF、CR 和 `0x20` 至 `0x7E`；
- 普通字符串由连续可打印字节组成；
- Unicode 选项识别 `可打印字节 + 00` 的零字节分隔宽字符串；
- 宽字符串的 Length 按原始字节数记录；
- Private、Mapped 默认启用，Image 默认关闭；
- 显示内容上限为 8,191 个字符，完整原始字节长度仍被保留。

参考实现：<https://processhacker.sourceforge.io/doc/memsrch_8c_source.html>
